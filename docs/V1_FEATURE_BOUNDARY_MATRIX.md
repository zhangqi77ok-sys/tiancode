# 湉码 / tiancode v1.0 功能达标与验收矩阵 (唯一验收合同)

本文档为湉码 / tiancode 正式冻结的唯一验收合同与真实交付基准。  
彻底作废早期草案中的虚构假交付项（如虚构的 Python/Air-Gap/Test Explorer/settingsStore 等），所有评价以当前真实运行路径（Wails v2 + Go 微内核 + Vue 3）与可验证事实为准。

---

## 🎯 唯一主旅程达标线

```mermaid
flowchart LR
    A["1. 打开真实项目"] --> B["2. 配置真渠道探活"]
    B --> C["3. 选择执行策略"]
    C --> D["4. 发起目标任务"]
    D --> E["5. 先检索/地图后改代码"]
    E --> F["6. Diff 审查与采纳"]
    F --> G["7. TDD 双栈测试验证"]
    G --> H["8. Git 本地提交"]
```

**主旅程达标验收标准**：
1. **Agent 不盲扫**：工作区提供一等检索工具 `search_workspace` (grep/find) 与顶层清单缓存；审查模式强制拦截写操作与深层非清单探索。
2. **任务看得见**：顶栏状态徽章（执行中 / 待确认 Diff / 已达上限 / 测试未通过 / 已完成 / 已中断）与阶段统计强同步；存在待确认改动时阻断新轮次并弹窗二次确认。
3. **编辑器够用**：文件树支持深层展开与文件名实时过滤；Monaco 编辑器支持多文件页签、未保存脏标记与磁盘读写。
4. **Diff 是主路径**：Agent 改写文件自动调出 Diff 视图并高亮变更；支持 Hunk 级与整文件级采纳/放弃。
5. **TDD 认真实栈**：支持 Go (`go test`) 与 Node (`npm test`) 真实双栈探测与执行；测试失败时顶栏红灯阻断，严禁模型虚假宣称完成。
6. **失败可续**：触顶、网络异常、中止均输出人话说明；输入「继续」自动接续前序目标。
7. **设置只承诺现货**：仅保留真实可落盘生效的能力（stdio MCP、渠道测速、本地规则/技能注入），剔除虚构入口。

## 📊 现货事实与功能达标矩阵

> **评分说明**：
> - 🟢 **达标**：主路径可独立完成、失败有交代、不靠用户猜、全链路测试验证通过。
> - 🟡 **半成品**：具备真实核心链路，仍需补齐部分工程体验或覆盖面。
> - 🔴 **不达标 / 实验性**：深度不足或非现货能力，严禁在 v1.0 中标为完成。

| 模块 | 现货事实 (Real Implementation) | 现状评分 | 交付事实与真实差距 (Gap to Bar & User Reality) |
| :--- | :--- | :---: | :--- |
| **安装 / 渠道 / 密钥** | Windows 免 UAC 绿色单文件向导安装 (`Tiancode_Setup_v0.0.1.exe`)；真实渠道探活；密钥落盘加密（AES-GCM）。 | 🟢 可用 | 主路径真实稳定，失败有交代，支持自定义路径与静默安装 (仅限 Windows 平台)。 |
| **对话循环 / 收尾 / 继续** | 单一收敛执行内核、TaskModel 目标持久化接续、人话收尾说明、驾驶舱任务态徽章。 | 🟡 半成品 | 骨架已跑通；但检索尚未做到内核级强迫先查后改、多轮上下文依靠字符预算截断，距离日常主力工具仍有交互距离。 |
| **策略闸门** | 支持 `analyze` (只读审查)、`implement` (直接改代码)、`tdd` (测试闭环)；默认 analyze，首轮硬闸看地图。 | 🟡 半成品 | analyze 物理拦截写盘已闭环；跳过策略收敛为保持默认 analyze；但 implement 模式下仍缺少硬性写前审查闸门。 |
| **工作区代码检索** | `plugins/tool/search` 提供原生 grep/find；已接入前端 Explorer，支持人工直接搜索代码与文件名；换工作区自动重绑。 | 🟡 半成品 | 算子可用且已打通人端使用，但尚未支持正则高亮替换、文件排除表达式与语法符号索引 (Symbol Index)。 |
| **工作区文件树** | 真实物理磁盘映射；1层受控懒加载，点击目录异步下钻；模糊过滤支持一键「全盘搜」快速通道。 | 🟡 半成品 | 懒加载可用，解决大项目 DOM 爆炸；但过滤仍依赖两段式检索，超大 monorepo 仍缺少本地目录离线索引。 |
| **Monaco 编辑器** | 集成多文件标签页 (Tabs)、切换内存缓冲区无损暂存、关闭脏标签页 Warm Cream 居中弹窗拦截 (零原生 confirm)。 | 🟡 半成品 | 页签草稿防丢已修好；但本质是具备基本编辑与单文件诊断能力的轻量编辑器，尚非具备跨文件重构/符号重命名的完整 IDE。 |
| **Diff 审查与采纳** | Agent 改动后自动聚焦 Diff；Hunk 行级采纳/放弃；发送下一句前强检测 pending Diff 弹窗阻断。 | 🟡 半成品 | hunk 与发送阻断真实可用；但当前模式属于「写盘后审查与回退 (Post-write review)」，未支持虚拟隔离区写前审批预演。 |
| **Git 源码管理** | 分支查看/切换/创建、快照 stash/还原、工作区/暂存区明细、提交说明生成与提交/推送。 | 🟡 半成品 | 日常分支、暂存与提交真实可用；无三向冲突合并界面与提交图谱 (Commit Graph)。 |
| **TDD 自动化验证** | `RunTDDValidation` 双栈探测：Go `go test` + Npm `npm test`（智能探测根目录与 `frontend/`）；测试失败红灯阻断。 | 🟡 半成品 | 双栈级联代码真实跑通；但缺乏按文件/包分级测试，前端用例级细粒度统计与 UI 报告面板仍待补齐。 |
| **MCP / 技能 / 设置** | stdio 真实拉起挂载；规则/技能落盘并注入模型；顶栏项目宪法透明弹窗查阅；七页签设置中枢。 | 🟡 半成品 | 能配能注入，彻底出清假 OAuth/SSE；但 stdio 导入诊断、错误可视化与插件市场生态仍待深化。 |
| **安全沙箱底座** | 路径物理沙箱（防越权/路径穿越）、高危命令拦截（rm -rf 等）、敏感凭据脱敏剥离。 | 🟢 可用 | Go 微内核 + SafetyRail 硬拦截严格生效，fail-closed 机制完备。 |
| **知识图谱 / 遥测大盘** | 基于 Go AST 扫描结构体拓扑；本地估算 Token 与开销。 | 🔴 实验特性 | 界面已明确标注为 `[实验]` (Beta)，仅供开发辅助参考，不作为主力交付承诺。 |

## 🚫 明确排除在 v1.0 验收范围外的演进特性

1. **Swarm 复杂多智能体编排**：v1.0 专注于单 Agent 高质量 Coding 闭环，不引入未稳定的实验性 Swarm 概念；
2. **多终端 PTY 虚拟终端**：当前保持静默无弹窗流式执行已足够满足工程闭环；
3. **LSP 完整语言服务器协议集群**：v1.0 依托编译器诊断与 Monaco 本地高亮，全套 LSP 纳入 v1.2 规划；
4. **Air-Gap 物理离线隔离**：已作废，不做虚假宣传。
