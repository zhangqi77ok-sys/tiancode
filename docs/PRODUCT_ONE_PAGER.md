# Tcode 产品一页纸 (Product One-Pager)

> **产品定位**：企业级安全、可审阅、可验证且完全可回滚的 Agentic AI 智能编码工作台 (Agent Coding IDE)。

---

## 🎯 一、核心定位与第一目标用户

### 1. 第一目标用户 (Target User)
**需要对 AI 生成的代码变更进行严格审阅、测试验证与无损回滚的专业研发工程师与企业架构师。**

### 2. 非目标用户 (Non-Goals)
- 仅需要简单代码补全/单行问答的初学者（推荐使用 GitHub Copilot / Cursor 基础 Tab 模式）；
- 追求全自动黑盒执行且不关心单测质量的用户。

---

## 💡 二、解决的核心痛点 (Problems Solved)

1. **AI 修改不可控与代码污染**：传统 AI 编程工具直接全量覆盖文件，破坏未保存代码；Tcode 提供**精细化 Hunk 级审查**与**写盘前 Git 影子快照 (Shadow Checkpoint)**，支持一键无损撤回。
2. **测试结果与命令执行脱节**：命令输出存在 `FFFF` 失败但误判为完成；Tcode 深度绑定测试输出，**单测未全量通过前绝对禁止标记为完成**。
3. **模型上下文黑盒与凭据泄露**：Token 水位计算混乱且源码硬编码 API Key；Tcode 提供**统一全局上下文遥测与非破坏性智能压缩**，源码与日志 100% 物理脱敏隔离。

## 🔒 四、核心差异化能力 (Core Differentiators)

- **任务必须有结尾（Human-Readable Endings）**：触顶、中断、上游 400/401/429/500 或网络异常统一输出清晰人话交代与后续建议，用户绝不面对「突然没了」；
- **「继续」无损接续（Session Task Continuity）**：会话挂载最小任务模型，多轮对话识别长句与接续意图，保留已探明上下文，严禁推翻重来；
- **改文件默认带出 Diff（Pending Diff Confirmation）**：写盘变更进入待核验文件池并在顶栏展示提示横幅，必须人工核验 Diff 确认采纳才算闭环完成；
- **策略与安全双重硬拦截（Strategy & Rail Protection）**：analyze 只读策略下内核硬阻断命令执行与写盘，TDD 模式下测试失败强阻断伪成功；
- **项目宪法透明可见（Constitution In Cockpit）**：对话顶栏直观展示已激活的规则与技能条文，注入透明可解释。

## 📦 五、现行架构与交付规范 (Current Architecture & Delivery)

- **正式名称**：`湉码 / tiancode`（桌面 AI Coding 智能体工作台）；
- **现行唯一发货架构**：**Wails v2 原生桌面端 + Go 微内核 + Vue 3 / Vite + TypeScript + Pinia**；
- **历史架构归档废弃声明**：
  - ⚠️ 历史基于 `React + Python (PyWebView/PyInstaller)` 的原型已彻底停用归档至 `archive/`；
  - ⚠️ 历史基于 `Tauri v2 + Rust Core` 的设计方案已停止实施并转入历史参考；
  - 团队及对外统一口径**只承认 Wails + Go + Vue 3**；
- **核心交互原则**：
  1. 任务必须有结尾（触顶、取消、上游400/500、空结束均有人话提示，绝不「突然没了」）；
  2. 审查类任务禁止无脑扫全库，先看地图再精准下钻；
  3. 「继续」= 接上一次任务目标，挂载 Session TaskModel，禁止推翻重勘；
  4. 改文件默认带出 Diff，人点接受才算完成；
  5. TDD 策略下测试失败则任务状态绝不是完成；
  6. 项目宪法（生效规约与技能）在对话顶栏显式可见。
- **Windows 安装包构建**：`powershell -File scripts/build-windows.ps1` 产出 `bin/Tiancode_Setup_v0.0.1.exe`。
