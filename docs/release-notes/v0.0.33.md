# tiancode v0.0.33

输入区减法：移除底部手动命令行（用户裁决"没必要"）。

## 变更

- **移除输入框下方的手动命令行输入**：模型跑命令与手动入口走的是**同一条**审批链（同一 shell 工具、同一超时、同一确认卡），重复入口只添杂乱；"自己想跑一条命令"直接在对话里说，或用快捷命令槽
- **快捷命令三槽保留**（0.0.26 的 build/test/run 一键按钮）：仅在配置了槽位时才出现在输入框下方——一个都没配时整行消失，不再有常驻的空行
- 后端 `RunUserCommand` 端点保留（快捷命令链复用）；前端 store 的死代码同步清理

## 验证

- 前端 42 文件 311/311（+1 例回归锁：手动输入框不复存在、快捷命令按钮仅配置后出现）、`vue-tsc` 干净、构建通过
- Go 零改动
