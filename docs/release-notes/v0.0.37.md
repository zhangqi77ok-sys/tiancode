# tiancode v0.0.37

视觉反馈：模型可以亲眼看自己改的页面。

## 截图进模型上下文

- browser 工具 `screenshot` 新增 `for_model` 参数：模型主动要求"看一眼页面"时，截图以图片形式进入它的上下文——UI 改动从"盲改"变"看着改"（改完自己看效果、对照设计判断、发现布局问题当场修）
- **成本护栏**：默认（不带 for_model）行为完全不变、零图像成本；原始字节超 1.5MB 拒绝进上下文并给出路（缩小视口重试）；失败的工具调用不送图
- **生命周期**：图像仅本回合可见（不落账本——账本里已有截图路径，之后回合模型可再截）；走三协议既有的多模态管线（OpenAI content 数组 / Anthropic image block / Codex 文字说明），与用户附件同一套代码
- UI 的截图卡片展示完全不变（Visual 给 UI、ModelImage 给模型，互不泄漏）
