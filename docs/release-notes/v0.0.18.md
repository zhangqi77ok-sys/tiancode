# tiancode v0.0.18

会话工作区完整跟随 + 启动恢复最近会话 + 连点切换竞态修复。

## 会话工作区完整跟随

- 点开的会话归属即视图上下文：有归属 → 新对话默认根带到该归属；无归属（纯对话/未分组）→ 默认根一并清空，新建对话延续纯对话（0.0.15 内部构建曾取"只在归属非空时跟随"的折中，用户实机反馈点纯对话会话后期望新建同样纯对话，改为完整跟随）
- 清空与切换都是显式可见的：顶栏立刻变为该会话的归属（无归属明示"这场对话没有工作区"）、侧栏空间高亮同步变化，不再是 0.2.37 担心的看不见的暗改
- 顶栏中段修正：非草稿一律显示这场对话自己的归属，绝不拿"下一场新对话"的根冒充；归属为空时明示而非留空（此前 `wsLabel.main` 算了没渲染）
- 只切根不 newSession：跟随 ≠ 抛掉正在看的会话；启动恢复不跟随（workspace 仍由用户显式进入）

## 启动恢复最近活跃会话

- 修复启动落在**最老**会话上的问题：会话列表按 ID 升序（文件名序），此前取 `[0]`；现按 `lastActiveMs` 取最近活跃的一场

## 连点切换竞态修复

- 翻页锚点 `olderFrom` 按会话各存一份：此前是全局单值，快速连点 A→B 时 A 晚到的尾屏会把 B 的锚点写成 A 的，B 视图向上翻页取错页、错页前插进 B 的缓冲；晚到的写入现在只落自己的 key
- "正在载入历史"按会话计算：先完成的会话不再提前熄掉当前会话的载入态
- 删除会话同步清理锚点与载入态

## 验证

- 门禁全绿：gofmt / vet / `go test ./...` / ARCH CHECK PASS；前端 `vue-tsc` 干净、39 文件 289 用例全绿（新增：跟随归属 / 无归属清空 / 纯对话不重复下发 / 摘要缺失不碰工作区 / init 选最近活跃 / 晚到尾屏不错写锚点 / 载入态跟随当前视图）
- 顺带修掉 FileDetailPanel 过时的关闭按钮测试选择器（此前是唯一红测试）
- 门禁期间既有抖动复现一次（`TestChatService_EmptyWorkspaceSessionStaysEmpty` 全量并行偶发，隔离单跑与整包复跑均绿，与本批纯前端改动无关）
- 环境备注：本机 Edge 154.0.4258.48 损坏（任何方式启动瞬间退出且无输出），门禁经 `TIANCODE_BROWSER` 指向 Chrome 通过；应用内 browser 工具同理
