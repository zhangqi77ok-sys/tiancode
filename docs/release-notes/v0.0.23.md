# tiancode v0.0.23

第三轮全栈审查的收口批：重试语义说清、跨会话搜索、渠道健康统计、数据备份与迁移。

## 搜索所有会话（Ctrl+Shift+F）

- 一个搜索框扫**所有**会话账本，回答"我上周让模型查过什么来着"（会话内 Ctrl+F 不变）
- 三处有界：最近 100 场会话 / 单账本 4MB / 50 条命中；只读扫描，回合进行中的半行照跳不误伤
- 点一条结果直接跳到那场对话的对应轮次（复用时间线跳转，不新造定位）
- 可勾"只搜当前工作区"；速查表（?）已登记

## 渠道健康统计

- 渠道管理里多一列**近 7 天成功率**（title 里有平均建流耗时/故障分类/最近错误原文）
- 故障切换是自动的（降档重试 + 自动禁用），这一列让它**可见**
- 无请求的渠道写"暂无数据"，不编 100%
- 数据按日聚合落盘（保留 8 天），不记 BaseURL/凭证/消息内容

## 数据备份与迁移（侧栏设置 → 备份与恢复）

- **导出**：整个数据目录（会话/记忆/渠道/语气/扩展/设置）打成一个 zip，文件名带版本与时间
- **恢复**：选包后先给摘要（文件数/会话数/来源版本/时间），确认才写入；可勾"只补缺失文件"
- 落地前自动把当前数据另存一份 `.bak` 兜底；解压防 zip slip（条目越界直接拒绝）
- 备份里含渠道密钥（与本机存储形态一致）——请像对待账本一样保管

## 重试语义澄清（行为不变）

- 核实结论：一次 Send 的上游请求数**≤ 4**（网关降档重试），调用层的建流重试在生产路径恒为 1
- 两条边界写进注释并加防回归测试：终态块失败不触发重试、机制性失败才重试

## 验证
