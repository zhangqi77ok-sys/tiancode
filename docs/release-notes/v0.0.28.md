# v0.0.28

## 修复

**右栏面板有了可见的关闭按钮** — 此前右栏打开后，tab 条上只有切换按钮，关闭只能靠 `Esc` 或去窗口最右缘点竖标图标，界面上找不到任何关闭入口。现在 tab 条右端固定一个 `×`，鼠标悬停会写明关的是哪一块（例如"关闭目录面板"）。关掉最后一个面板时右栏整体退场。

**侧栏设置菜单同样补上 `×`** — 这个菜单此前只能靠 `Esc` 或点别处关闭，现在模型名右侧就是关闭按钮。

两条路径的原有行为全部保留（`Esc`、点外面、点原按钮仍能关），只是把隐式入口显式化。

## 安装

下载 `tiancode-setup-v0.0.28.exe` 安装（升级会自动关闭旧版）；便携版 `tiancode-v0.0.28-portable.zip` 解压即用。
