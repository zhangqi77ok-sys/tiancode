新增：内部诊断日志（“卡住时不用再截图猜”）。

## 新增：诊断日志

- **每次对话的诊断轨迹按天落盘**（保留 7 天）：
  - 轮次开始：会话、工作区、消息摘要、附件数、@引用数
  - 上游请求：主机、模型、协议、字节量（**不记凭证与消息全文**）
  - 建流完成/失败耗时、流结束原因（done / error / cancelled / idle_timeout）
  - 看门狗触发、问答/审批等待与恢复、工具执行
- **设置 → 模型渠道 → 打开日志文件夹** 一键直达
- 卡住时按时间翻当天日志，最后一行即定位：
  - 停在 `upstream request` 后无 `upstream connected` → 挂在建流（网络/中转）
  - 停在 `upstream connected` → 流挂起，等待流层 60 秒空闲看门狗收束
  - 有 `watchdog fired` → 零事件看门狗已自动中断并说明原因

## 另外

- `EndReason` 增加可读字符串（日志里是 `reason=done` 而不是数字）
- 日志写入即关句柄，不锁目录/文件；失败静默（日志不可写不影响业务）
