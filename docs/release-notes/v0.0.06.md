# tiancode v0.0.06

修复版：@ 文件引用与任务清单生命周期。

## 修复

### @ 引用真正生效

- **选中文件后消息里的 `@相对路径` 会被后端真正读成附件交给模型**——图片直接进上下文、
  小文本文件内联、大文件附路径；此前 @ 只在输入框弹菜单、插入一段裸路径，模型不理会
  就没有任何效果
- **草稿（还没发过消息的新对话）也能用 @**：文件列表来自顶栏当前工作区——发送后这场
  对话就归属该工作区，搜索与发送看到的是同一个根
- 纯对话（无工作区）时 @ 会显示明确提示，不再静默没反应
- 引用不存在或越界的路径不会报错（原文保留）；@ 不会成为绕过工具根边界的口子

### 任务清单不再一直显示旧的

- **发送新消息即作废上一份清单**：新任务开始时旧清单立即退场，不会一直挂着
- **全部完成后悬浮件自动退场**：任务做完清单就消失；重新打开会话也不会再浮出
  早已完成的旧清单
