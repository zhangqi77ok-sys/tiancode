# tiancode v0.0.42

反馈闭环补全：前端改动不再是"盲写"，项目规矩不用再每轮口述。

## 前端写后类型诊断（C-FS-8 扩展面）

- 写完 `.ts` / `.tsx` / `.mts` / `.cts` / `.vue`，系统自动跑工程级 `vue-tsc`/`tsc --noEmit`，把**本文件**的类型错误以内联回执带回——模型当场知道改没改对，不再等 build
- 只展开本文件的诊断，其它文件的错误给计数（不淹没、不超预算）；全干净静默通过；无依赖/无 tsconfig/无检查器优雅跳过（自动钩子静默、手动 `fs.diagnose` 明说）；退出异常且无输出 = 不可判定，绝不冒充"通过"
- 工程定位：从文件所在目录向上找 `package.json`+`node_modules`（支持 src 嵌套与 monorepo 上一层 tsconfig）

## 项目规则注入 AGENTS.md（C-APP-5）

- 工作区根放一份 `AGENTS.md`，正文自动快照进每轮系统说明——构建命令、代码风格、禁区由项目自己声明，换项目自动跟随，不再靠用户每轮口述或在全局记忆里混放
- 上限 8KB（超出头尾保留并注明节选）；没有该文件零噪声；每轮快照、逐字稳定，与 prompt cache 完全兼容

## 关于用量面板

审查中发现用量统计在 0.0.31 是"删除批"（用户审查后的刻意决定），本轮不复活；顶栏每轮 prompt token 油表（0.0.09）继续承担成本可见性。
