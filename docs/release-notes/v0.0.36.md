# tiancode v0.0.36

审查修复批：四批新功能（编译诊断/自愈循环/多段编辑/方案模式）的 4 个 bug。

## 修复

- **autofix 事件先于认领**：检查自愈触发时先推 `chat:autofix` 再认领会话——认领失败（用户正在发消息）时前端已被置为"运行中"且永远等不到终态，会话卡死只能重启。改为**先认领、成功才发事件**
- **诊断误报"通过"**：`go vet` 异常退出且输出无可解析诊断时（嵌套 module、模块外目录等机制性失败），此前被当成"编译诊断通过"——把"没跑成"说成"没错误"会误导模型。新增"不可判定"形态：手动诊断明说、自动诊断保持静默（不为嵌套 module 的每次写入制造噪音）
- **方案确认卡误弹**：方案回合发送失败时 `planTurn` 残留，之后任何无关回合收尾都会误弹方案卡；方案回合没产出助手文本时（只调工具就收尾）会把**上一轮**的回答错当成方案。两处边界都已收紧
- 附带：`planTurn` 残留、方案文本取值边界均属 0.0.35 未装机前的窗口期修复，无升级数据迁移

## 验证

- Go 32 包全绿（+1：嵌套 module Inconclusive 回归，实证 vet 在该场景确实失败）；ARCH CHECK PASS
- 前端 315/315；`vue-tsc` 干净
