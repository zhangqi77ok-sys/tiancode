# tiancode v0.0.24

托盘常驻 + Git 面板 + 审批白名单 + 成本估算。

## 系统托盘（PENDING 专批落地）

- 托盘图标常驻：左键唤回主窗口；右键菜单「显示主窗口 / 新建对话 / 检查更新 / 打开日志目录 / 退出」
- **关窗新语义（用户裁决）**：点 X / Alt+F4 / 系统关窗 = 隐藏到托盘（后台轮次继续跑），真正退出只从托盘菜单走；首次隐藏给一条发现性提示
- 托盘「新建对话」唤回窗口并回草稿态；「检查更新」走应用内既有确认流程
- 依赖：energye/systray v1.0.3（Apache-2.0，vendor 入库保持离线可构建）
- 实机验证：托盘图标注册（系统 NotifyIconSettings + 消息窗口在案）、WM_CLOSE → 隐藏且进程存活、左键 Invoke 唤回；右键菜单为系统原生 UI，请装机后手点确认

## Git 面板

- 右栏新「Git」tab：工作区变更清单（未跟踪/已修改分组，porcelain 状态码）+ 点文件看单文件 diff + 「生成提交说明并提交」复用既有确认链
- 后端新增结构化 `status --porcelain -z` 解析（重命名记录拆分、畸形行跳过）；修复 runGitCmd trim 吃掉状态列首空格的解析错位（新增不 trim 的 raw 变体）

## 审批白名单

- 工作区设置新增「Shell 审批白名单」：命令以配置的前缀开头（如 `git status`、`go test ./...`）时自动放行，不再每步弹确认卡；未命中照常确认
- 只放行、绝不反向加严；按工作区各存一份（不同项目安全基线不同）；规则由用户显式配置，编排层只做前缀匹配，不做命令语义分析（ADR-0007 纪律不变）

## 成本估算与用量趋势

- 渠道配置新增输入/输出单价（$/1M token）；「统计」面板按当前激活渠道单价显示近 7 天成本估算（多渠道混用时明示为近似值）
- usage 事件补时间戳，统计面板新增近 7 天逐会话趋势条；旧版本（无时间戳）的用量只计累计、不倒填

## 修复

- 升级安装优雅退出：自更新置真退出标志后再拉安装器——此前托盘版 OnBeforeClose 把安装器的关闭请求也转成"隐藏"，导致安装器强杀旧实例（升级日志"未响应关闭请求"）
- 手动双击安装器覆盖运行中的旧实例仍会强杀（安装器的 WM_CLOSE 与 Alt+F4 在应用侧不可区分）——已知边界，登记 PENDING；常规路径请用应用内「检查更新」

## 验证
