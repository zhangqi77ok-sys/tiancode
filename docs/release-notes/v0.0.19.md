# tiancode v0.0.19

工作台体验批量升级：记忆系统 + 会话迁移 + 用量统计 + 七项 UI 打磨 + 底层债修复。

## 长期记忆（两级）

- 模型有了能记住事的地方：`memory` 工具（read/append/delete，global=用户偏好 / workspace=项目约定），Markdown 行式存储（%APPDATA%\tiancode\memory\），单文件 32KB / 200 条双硬顶，超限显式报错让模型先清理
- 每轮系统提示自动注入记忆段（无记忆不占上下文）；回合内改动下一轮生效（快照语义，prompt cache 不受影响）；纯对话会话照常用全局记忆
- 空根哨兵错误（ErrNoWorkspace）：注入路径把"无工作区"当常态，工具路径显式告知模型

## 会话迁移空间

- 会话行新增「移动到空间」：归属是账本事实（新 `workspace_move` 事件，最后一次说了算），侧栏分组、顶栏标签、工具根同一规则——迁移后下一轮文件操作落新目录，绝不出现"显示在新空间、写进旧目录"的分叉
- 目标不存在/非目录当场拒绝；移出空间 = 纯对话归属（工具下线）；运行中拒绝迁移

## 用量统计

- usage 首次落账本（每收到一次上游用量追加一行，Meta 扫描聚合），重启不再清零
- 右栏新增「统计」tab：按会话的输入/输出/总量排序，全部累计；旧账本不计入（照实注明）

## UI 打磨（七项）

- 后台会话终态主动提示：toast（可点跳转）+ Windows 任务栏闪烁（FlashWindowEx，不抢焦点）——"跑完了"穿透当前焦点
- 右栏宽度可拖拽（左缘把手，localStorage 记忆，300px 下限）
- 顶栏工作区中段可点：弹菜单（复制完整路径 / 进入最近工作区 / 选择其他目录 / 退出纯对话）
- 文件树自动跟手：fs 写/改卡落定自动重载（含「应用到文件」与「恢复写入前」），已展开层级保留不被拍平
- 主题改三选一（跟随系统/浅色/深色），固定深色不再踩三下循环
- Ctrl+K 命令面板：跳会话 / 进工作区 / 开设置一个入口（↑↓ Enter Esc）
- Ctrl+F 会话内搜索（消息正文，命中计数 + 跳转高亮）；? 呼出快捷键速查；输入草稿 localStorage 持久化（重启不丢半句话）

## 底层债

- `ResolveSessionPath` 补符号链接解析：root 内指向根外的链接不再被字面前缀比较误判为"在根内"（越界绕过修复）
- netproxy 补齐单测（此前零测试）：直连/缓存复用/非法地址/不支持协议/Reset 五条分支
- 账本投影大小防线：账本超 256MB 显式报错并给出路，绝不静默吃内存

## 验证

- Go 全量 25 包全绿（新增 memory 包 6 例、netproxy 5 例、app 层记忆注入/迁移/用量 4 例；IPC 端点清单 +2：`MoveSession`/`FlashWindow`）
- 前端 vue-tsc 干净、39 文件 293 用例全绿（新增：后台终态提示/树刷新信号/迁移/treeRev 自动重载保展开态）
- arch_check 抓到并修掉 memory 工具缺超时契约（R3，5s 有界）
