# tiancode v0.0.43

闭环补全：任何项目获得与 Go 同级的"改→检查→自愈"环；人不在窗口前也不错过任务节点。

## 项目检查命令进 AGENTS.md（C-APP-6）

- 工作区根 `AGENTS.md` 的 frontmatter 声明 `check: npm run build`（或任意命令），即成为该项目的工作区检查命令项目级默认值——仓库克隆到哪台机器，检查闭环跟到哪
- 优先级：工作区设置里显式配置的命令永远优先（用户机器上的临时覆盖高于仓库声明）
- 命令同时注入环境事实：模型知道它存在，改动后会主动跑它确认；回合终态系统照旧自动执行、失败进 0.0.34 自愈循环
- 解析不出 = 与"未配置"完全一致，绝不猜命令

## 系统通知（C-APP-7）

- 窗口失焦时（用户在别的应用、或缩到托盘），三类事件弹 Windows 系统通知：后台回合完成/出错、等待审批、等待回答——长任务跑完不用切回来盯梢
- 判定在前端（`document.hasFocus`，最准的"用户看不看得见"），后端是无状态绑定：文本有界、XML 转义防注入、全局限速 3s（连发合并）、失败上抛不静默；零新依赖（PowerShell 调 WinRT）
- 聚焦时零打扰；旧内核缺方法自动降级

## 压缩呈现补全（C-APP-8）

- 0.0.41 的历史压缩此前只在模型侧生效，油表现在会标注"历史已压缩"（与折叠明细分开写清），旧内核不带字段时自动兼容——"折叠绝不静默"的 UI 侧还账
