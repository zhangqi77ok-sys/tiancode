# tiancode v0.0.05

修复版：附件显示与状态卡死问题。

## 修复

- **图片/文件附件在气泡中可见**：发送的图片在用户气泡上方显示缩略图（点击放大），文件显示名字与「已内联/只附路径」标记；重新打开会话后仍能看到（重放时后端读取附件文件生成图片）
- **发送即本地回显**：图片粘贴/上传后发送，气泡立即显示，不再需要刷新或切换会话
- 保留 0.0.10 全部能力：粘贴/拖入/上传三路附件、@ 文件引用（按当前会话工作区）、代码块「应用到文件」、改文件先确认再落盘、停止键打断当前工具

## 说明

- 上游 90 秒无响应会自动中断并提示（零事件看门狗）；生成中也可随时点「中断」
- 若上游长时间无输出，卡片会显示明确的超时错误而不是无限转圈
