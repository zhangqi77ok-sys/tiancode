# tiancode v0.0.03

第二轮审计 8 项修复。

- 工具根按会话持有：fs/shell/git/search 每会话一份，根由账本首个 workspace 事件固定（消除并行竞态写错项目）
- 元数据只读扫描：回合进行中刷新列表不再截断账本尾部
- 审批闸门：新装默认对 shell 与 ext_manage 生效；审批独立超时按拒绝处理；确认卡带会话名
- search 逐文件真实路径校验：区外跳过并汇总、不因一个链接整次失败
- write/replace 参数上限 32MB：超限整次失败、原文件不动
- MCP dropClient 锁瞬间化：拨号在锁外，卡住的服务器不堵全会话

安装：`tiancode-setup-v0.0.03.exe`（支持 `-quiet`）；便携包为 zip 版。
