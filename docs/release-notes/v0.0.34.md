# tiancode v0.0.34

编程循环强化：检查自愈循环 + 多段编辑。

## 检查自愈循环

- **测试红了，系统自动开一轮定向修复**：回合正常收尾后工作区检查（checkCommand）报告问题时，系统自动启动一个修复回合——系统留痕说明缘由与位置引用，模型带着失败点继续修，直到检查变绿（或预算用尽）
- **验证有保证**：位置引用与界面上的检查结果列表同源；修复回合经与普通对话完全相同的事件桥（增量/工具卡/审批/终态）
- **刹车齐全**：预算 2 轮封顶；用户中断、看门狗超时、错误收尾**绝不**触发自动修复（"停"就是停）；真实用户消息发送即重置预算（新的一手重新计数）；会话忙时自动修复静默让位，绝不与用户抢回合
- 修复回合的留痕随账本持久化：重启后时间线/重放照样看得见"这一轮为什么存在"

## 多段编辑

- `fs.replace` 新增 `edits` 形态：一次调用传多组 `{target, replacement}`，**原子应用**——任一段匹配不上则整次失败、文件零修改（沿用单段的"零匹配给最近上下文"体验）
- 后面的段在前面的段应用后的内容上匹配（顺序依赖合法）；大文件多处修改从 N 次往返变 1 次，上下文也省 N 份回执
- 单段 `target/replacement` 形态完全不变；两套形态混用显式拒绝

## 验证

- Go 32 包全绿（新增：自愈触发/预算重置/中断不触发 3 例 + 端到端 1 例；多段编辑 5 例）；ARCH CHECK PASS
- 前端 42 文件 312/312（+1：autofix 事件置 running 与说明气泡）、`vue-tsc` 干净
