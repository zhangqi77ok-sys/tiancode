# tiancode v0.0.22

补丁版：修复 0.0.21 实机走查抓到的关窗确认漏判。

## 修复

- **关窗确认补洞（用户命令行路径）**：0.0.21 的关窗拦截只把"模型轮次在跑"算作运行中；**用户在输入框下方命令行执行命令**（审批等待或执行中）点 X 时，应用会直接退出、正在跑的命令随进程一起被杀。现在命令行执行中也纳入判据：审批等待或执行期间关窗一律先弹"还有会话在运行"，确认才退。
  - 发现方式：0.0.21 装机实测——命令行触发审批卡后点 X，确认框没出现、进程直接退出。
  - 修复范围：编排层增加一个原子标志（用户命令行活动），`AnyRunning` 判据纳入它；模型轮次的原有判据与 1 秒防抖不变。

## 验证

- 新增测试：判据层两态（标志位置位/复位）+ 集成路径（审批闸门拦住命令行 → `AnyRunning` 为 true；拒绝答复后复位）。
- 门禁：`go test ./...` 全绿、ARCH CHECK PASS、gofmt 空输出、前端构建通过。
- 实机：0.0.21 → 0.0.22 静默升级安装通过（注册表 DisplayVersion=0.0.22）。

## 已知边界

- 本版只改关窗判据，不改审批闸门、轮次管理或执行器；0.0.21 其余功能（后台审批提示、记忆管理、时间线跳转、忽略清单一致、更新包 sha256 校验）不变。
- 0.0.21 的 GitHub Release 保持原样（不重打同号包），该版本存在上述关窗漏判，升级到 0.0.22 即修复。
