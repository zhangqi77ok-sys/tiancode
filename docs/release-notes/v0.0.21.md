# tiancode v0.0.21

第三轮全栈审查的落地批：两个实打实的缺陷修复、更新链真校验、记忆透明化、时间线跳转、忽略清单一致性。

## 缺陷修复

- **后台会话等审批/答复不再静默**：后台会话模型调 shell 等你批准（或 ask_user 提问）时，toast 可点跳转 + 任务栏闪烁穿透当前焦点——此前整轮无声挂起，唯一线索是侧栏小标
- **关窗不再杀进程陪葬**：后台还有轮次在跑时点 X 先弹确认框（确认才真退）；没在跑时行为不变

## 更新链完整性升级

- **安装包 sha256 校验**：发布脚本随包上传 `.sha256` 清单，应用内更新下载后验哈希，不匹配当场删除——"TLS + 尺寸"的诚实边界升级为真校验；旧版 release 无清单资产时回退旧行为并写日志

## 记忆透明化

- **记忆管理面板**（侧栏设置 → 记忆）：两级列表（全局偏好 / 本项目约定），逐条删除（与模型侧同一行号锚点）、一键清空先确认——此前模型能记用户却看不见

## 体验

- **时间线点击跳转**：点任一轮的正文跳到消息流对应位置（长会话自动向上补页），回滚前先看清那轮干了什么
- **忽略清单一致性**：右栏目录树与模型的 fs list/tree 接入统一忽略清单——node_modules/.git 等不再原样出现在目录树和模型输出里（此前与搜索、@ 引用的过滤不同源）

## 验证

- Go 全量 31 包全绿 + ARCH CHECK PASS；前端 vue-tsc 干净、40 文件 300 用例全绿
- 新增测试：关窗判据与防抖 2 例、记忆视图/删除/清空 3 例、时间线跳转 2 例、sha256 验哈希 4 形态、忽略过滤 2 例

## 下载

- `tiancode-setup-v0.0.21.exe` —— 安装器（推荐）；升级自动关闭旧版、覆盖安装并重启
- `tiancode-v0.0.21-portable.zip` —— 便携包（免安装）
- `.sha256` —— 两个产物的 SHA256 清单（应用内更新自动校验；手动下载可用 `certutil -hashfile <文件> SHA256` 比对）

数据全在本地（%APPDATA%\tiancode），卸载不丢会话；上游在海外时请在「渠道管理」配置全局代理。
