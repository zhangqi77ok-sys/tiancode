# tiancode v0.0.32

代码智能批次：编译诊断 + 符号大纲——把"改动→知道改没改对"的反馈压到秒级。

## 编译诊断（自动 + 手动）

- **写完 `.go` 自动诊断**：`fs.write` / `fs.replace` 落盘后系统自动对所在包跑 `go vet`（含 `_test.go`——`go build` 不查测试文件），编译/类型/未定义错误以 `file:line:col` 形态内联回当次工具结果，模型在同一回合内自纠，不再"写完靠猜"等全量构建
- 干净时静默（不制造噪音）；诊断超时/跳过（非 Go module、testdata/vendor）只附一条说明，**绝不改写写入的成功语义**——诊断是信息，不是闸门
- `fs.diagnose` 手动触发：干净明说"通过"、跳过明说原因、错误带可点 `path:line:col`（与界面的可点位置链路同源）
- 引擎取 `go vet` 子进程：不依赖 gopls、不 vendor x/tools，装完即用；go build 缓存温热后单包秒级

## 符号大纲

- `fs.symbols`：文件符号骨架（函数/方法/类型/常量，带行号）——先读大纲再精读，模型定位代码不再靠多次 grep 试错，省上下文预算
- Go 走 go/parser 精确解析（签名即源码原文，多行折叠）；ts/js/tsx/jsx/mjs/py/md 为正则启发式并**明确标注**；其余扩展名显式说明暂无引擎；300 条有界
