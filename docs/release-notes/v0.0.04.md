# tiancode v0.0.04

桌面 AI 编程智能体（Windows）。本版包含自 v0.0.03 以来的全部改进：

## 圈速与上下文治理

- **只读工具并行**：模型一次要读多个文件/多处搜索时并发执行（写类操作仍严格串行），多文件场景圈速提升约 3 倍
- **上下文油表**：顶栏实时显示本轮 prompt token（上游用量直读，不编造百分比）；旧轮次的只读读数自动收成单行，最近 2 轮保持全文——上下文留给有效信息
- **截断保尾部**：命令输出/大 diff 超限时保留头部+尾部+中间丢失标注——测试 FAIL 汇总不再被截没

## 操纵机构

- **write 整读门卫**：模型没整读过文件就不能整体覆盖（防止只读片段后写丢后半段）
- **恢复写入前**：每次文件修改可一键回退到修改前（文件后来被手动改过时会拒绝并说明）
- **read 行号化**：`12|func main()` 格式，按行分段替代字节偏移，中文永不截半
- **replace 零匹配给上下文**：失败时显示最相近行的前后 2 行
- **命令过程可见**：长命令执行中输出实时滚动到卡片，不再黑盒等待

## 驾驶舱

- **本轮变更审查带**：输入框上方收拢本轮所有文件改动，点开即 diff + 一键恢复
- **@ 文件引用**：输入框输入 `@` 直接引用工作区文件，模型省一步找文件
- **顶栏显示这场对话正在用的路**：主标签是当前会话的工作区，副标签才是新建对话将用的目录

## 界面

- 深色主题（跟随系统/手动切换）
- 工具卡执行中实时生长、write/edit 默认展开 diff
- 审批卡改为人话主内容（命令/路径/危险信号），原始 JSON 折进详情
- 模型/渠道/技能/MCP 统一入口；快捷键（Ctrl+N 新建、Ctrl+I 聚焦、Ctrl+↑↓ 切换会话）
- 导出会话可复制 Markdown 或另存为文件（生成中也可导出）

## 安装

- `tiancode-setup-v0.0.04.exe`：安装器（推荐），支持 `-quiet` 静默安装
- `tiancode-v0.0.04-portable.zip`：便携包

## 说明

- 数据目录：`%APPDATA%\tiancode`
- 支持全局上游代理配置；支持 OpenAI 兼容 / Anthropic / ChatGPT 订阅账号等多种渠道
- MCP 与 Skill 可由 AI 自行管理（受审批闸门约束）
