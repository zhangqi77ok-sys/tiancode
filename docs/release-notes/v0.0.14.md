# tiancode v0.0.14

主界面仪表化 + 长会话减重 + 编程场景三块最小能力。

## 外形

- 对话列限宽居中；侧栏/右栏用表面色差分区，去掉两条硬分割线
- 顶栏产品标记更新；空态重排为一件事：当前模型 + 当前工作区 + 三条可点建议（纯对话是一等模式）

## 驾驶位仪表

- 模型选择器进输入框左侧（点击只切模型；渠道/Key/代理仍在渠道管理）
- 上下文余量进输入框右侧，与顶栏油表同源；窄窗口（<1280）下仍可见
- 超上下文折叠时逐项写明折了什么：旧工具输出 / 图片 / 重复读 / 旧回复，绝不静默丢历史

## 代码可读性

- 高亮补 c、css、java、rust、powershell（powershell 不再别名 bash）；vue 映射 xml 语法
- 代码块改用独立中性底色，与对话气泡分离

## 长会话减重

- 流式增量合并成单条账本事件：几千条 delta 的会话从源头不再产生
- 切换会话先出最后一屏，向上滚动再补更早的历史（分页 + 服务端缓存）
- 折叠优先级重排：旧工具输出 → 旧图片 → 重复读同一文件去重（只留最近一份全文）→ 只读窗口收窄 → 最后才折叠旧回复正文

## 三块最小能力

- **文件可编辑**：右侧文件详情面板的正文可以直接改，保存走「应用到文件 / 撤回」，截断预览禁止编辑
- **生成提交说明**：本轮改完后在「本轮变更」点「提交说明」，按本轮 diff 生成；确认框可改，确认后才执行 git add / commit（git 工具仍只有只读 status/diff/log，push/reset/clean 无实现路径）
- **命令行**：输入框下方可直接输入命令执行，复用现有 shell 超时与审批闸门（闸门含 shell 时与模型命令走同一张审批卡）

## 验证

- Go 全量 25 包全绿 + ARCH CHECK PASS；前端 vue-tsc 干净、39 文件 285 用例全绿
- 门禁期间实测记录：浏览器端到端测试在全量并行时偶发启动失败，隔离单跑稳定通过（高负载抖动，与本版改动无关）

## 下载

- `tiancode-setup-v0.0.14.exe` —— 安装器（推荐）：安装 + 快捷方式 + 卸载项；升级会自动关闭运行中的旧版
- `tiancode-v0.0.14-portable.zip` —— 便携包（免安装，解压即用）

数据全在本地（%APPDATA%\tiancode），卸载不丢会话；上游在海外时请在「渠道管理」配置全局代理（如 http://127.0.0.1:7897）。
