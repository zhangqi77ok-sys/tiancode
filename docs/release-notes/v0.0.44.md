# tiancode v0.0.44

技能与模型的两块拼图：项目私有技能随仓库走，换个模型重答只影响一轮。

## 工作区级技能（C-APP-10）

- 工作区根放 `.tiancode/skills/*.md` 即成为该项目的私有技能（frontmatter 声明 name/description，缺省用文件名），与全局技能合并注入、`skill` 工具可直接取用
- **同名技能工作区覆盖全局**——项目约定优先于个人收藏；模型也可以自己用 fs 写技能文件（自助沉淀项目套路）
- 纪律：文件数 ≤50、正文 ≤32KB 有界（清单进每轮系统说明，不能被无界目录撑爆）；目录缺失零噪声；空文件丢弃

## 会话内指定模型重答（C-APP-9）

- 输入框新增模型选择器：默认"跟随默认渠道"，选定后本轮发送（含重跑重答）用指定模型——**只影响这一轮，不改默认渠道**，下一轮回归默认
- 模型列表来自全部可用渠道的并集；非法模型后端校验拒绝（必须在某条渠道的模型列表里），绝不拿任意字符串打渠道

## 验证

- 契约登记：C-APP-9/10
