# tiancode v0.0.02

外部代码审计 9 项修复。

- 多会话串根：发送前按会话账本归属切回工作区
- shell 后台任务孤儿进程：SetWorkspace 与应用退出时收进程树
- 目录选择文案诚实化；fs/search 解析符号链接拒绝越界
- 工作区路径规范化（尾反斜杠不再让前缀比较误判）
- fs.read 10MB 硬顶（超大文件给分段查看指引）；shell 超时钳制
- 审批清单回合快照；工具摘要与 git 输出按 UTF-8 边界截断（中文不再乱码）
- MCP dropClient 读-比-删进锁

安装：`tiancode-setup-v0.0.02.exe`（支持 `-quiet`）；便携包为 zip 版。
