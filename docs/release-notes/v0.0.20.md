# tiancode v0.0.20

时间线（按任意轮回滚，保留对话历史）+ 自动更新。

## 时间线

- 右栏新增「时间线」tab：按用户消息分轮列出历轮改动（锚点 + 该轮文件，已回滚的划线标记）；数据来自账本只读扫描（两趟扫描：先收集已消费检查点再组表——单趟边扫边标会把所有项错标成可撤，测试抓到后改掉），长会话也能看全史
- 每轮「回滚到此轮之前」：把工作区文件恢复到该用户消息时的状态（该轮及其后改过的文件，同文件取最早检查点——与重跑的文件恢复完全同规则），**保留对话历史**（不 fork、不重发）；消费的检查点逐个落 `round_revert`，「撤回本轮」不再重复处理
- 运行中拒绝回滚；锚点必须是未分叉丢弃的用户消息；部分文件撤不回（哈希不符/已删除/超限）逐条列出绝不静默

## 自动更新

- 顶栏图标菜单「检查更新」：查 GitHub 最新 release（走全局代理，与渠道同源）→ 版本比较 → 确认框（版本跨度 + 包大小）→ 下载到临时目录（尺寸校验，不完整即删）→ 拉起安装器 `-quiet -relaunch` → 应用自退，安装器优雅关闭旧版、覆盖安装、自动重启新版
- 新包 `internal/platform/selfupdate`：版本比较纯函数（宽容解析不 panic）、检查/下载 5 例单测；诚实边界：资产完整性由 GitHub TLS + 尺寸校验保证，发布流程无签名清单，不假装更强
- 安装器新增 `-relaunch`（装完重启新版，失败只记 stderr 不报错框——安装成功不该被"没自动重启"伪装成失败）
- dev 构建不检查更新（没有基线就不胡乱建议升级）；比最新版旧才提示（不降级）
