# tiancode v0.0.07

修复版：任务清单重放复活（端到端实测发现的真 bug）。

## 修复

### 任务清单重放复活（实测发现）

- **场景**：任务 A 做到一半（清单停在 in_progress），用户发了新消息问别的——
  聊天里旧清单已经退场，但**重启或切回会话时，半程的旧清单又浮回来**
- **根因**：账本重放投影取"最后一条 EventTodo"，不检查它之后有没有新的用户
  消息；前端"全部完成退场"规则只兜得住全 done 的快照，半程快照会复活
- **修复**：重放投影增加生命周期规则——todo 之后出现过新的用户消息（= 新任务
  开始），旧清单不再投影；清单仍是当前任务时照常恢复最新快照

### 实测覆盖（本轮新增）

- **端到端测试打穿全链路**：`SendWithAttachments` → 会话工作区解析 → @引用
  物化 → 账本 → 重放 → **mock 上游收到的真实请求体**断言——@main.go 的内容
  第一轮进入模型上下文、第二轮重放历史仍不丢
- 端到端：todo 投影生命周期（旧清单不复活 / 当前任务恢复最新快照）
- 实机截图验证：历史消息的图片附件在气泡上正常显示（0.0.05 修复生效）
