# tiancode v0.0.35

方案模式：大任务先出方案，确认后再动手。

## 方案模式（Plan 模式）

- **输入框新增「方案」开关**：开着发送的一轮是**只读调研**——模型充分读代码、查搜索、看 Git 后输出一份可执行的实施方案（改哪些文件、实施步骤、怎么验证、风险与回退）
- **只读是结构保证，不是君子协定**：方案回合的工具集被整体重建——shell、浏览器、memory、扩展管理**不在场**；fs 为只读包装（write/replace 及未来任何新动作一律业务拒绝）
- **方案确认卡**：方案回合结束后弹出，点「按方案执行」→ 方案文本随一条普通消息发回，进入真正的执行回合（写路径恢复在场，审批闸门/自愈循环/白名单等既有机制照常生效）；取消则什么都不发生
- 方案文本就是一条普通助手消息：时间线、重放、导出全部天然支持
